How to get the CSV (1 minute)
  1. Open your address on the block explorer of the network: robin.etherscan.io (Robinhood), etherscan.io (Ethereum) or bscscan.com (BNB Chain).
  2. On the Transactions tab press Download CSV Export (under the list of transactions, or the download icon above it).
  3. Pick the whole period, leave the type as ordinary Transactions, confirm the captcha and download the file. It is called export-0x….csv.
  4. Drop the file on this page or press Load explorer CSV…. The page reads only these transactions from the chain, so it takes a few seconds. The wallet address is taken from the file name.

Download the file again whenever you want fresh data: the page does not follow new transactions by itself. The explorer may limit the export to the newest few thousand rows.

Your Metric swaps and liquidity, from the chain

Metric has no wallet API, but every swap and every deposit into a pool is an event on the blockchain. Enter your address and load the transaction list exported from the explorer: the page shows your liquidity positions per pool and the history of your swaps with their volume.

Everything runs in your browser. The address is sent only to the Metric API (pool list, prices, positions) and to the public RPC of the chain. USD values use the current prices of the Metric API.

Unofficial project, not affiliated with Metric. Data: api.metric.xyz and the public RPC of the network. Liquidity shows what was deposited and withdrawn, not the present value of a position.
